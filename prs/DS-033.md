## Bench evidence (recorded 2026-11-23, this worktree, debug profile unless noted)

Harness shape: `ds-bench` boots ds-vdev (throttled) + the daemon stack **in-process** on
a tmp dir (ds-ipc control server over the shared `Store` + the DS-031 `FrameService`
serving `<dir>/stream.sock`) — `daemon::run` does not serve `stream.sock` yet
(docs/components/frame-service.md §wiring), so the bench cannot drive the shipped
`ds-daemon` binary for frames; the library wiring is identical to the DS-031 in-crate
integration test. Telemetry for `key:N` targets is read via the `stream-stats` op
(ipc-message.json's `get` path pattern excludes `:`). Peak RSS is `/proc/<pid>/status`
`VmHWM` of the bench process, which hosts the daemon tasks in-process.

Gate 1 — `cargo test -p ds-bench`: EXIT=0 (12 lib unit tests: percentile math,
synthetic budget evaluation, stack boot; 1 integration test: 2 s x 32 fps end to end;
1 doc test).

target key:0, query /controls/keys/0), exit 0:
