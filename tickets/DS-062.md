## Context

Phase 6 includes "CLI self-description conformance" (docs/60-roadmap.md phase 6 exit:
every CLI verb has --help and appears in ds schema output). The contract is normative in
docs/contracts/cli.md §1-5; AGENT-WORKFLOW.md §CLI self-description contract; R1/R10.
DS-016 implemented the phase-1 verbs; later phases add verbs — this ticket locks the
whole surface with black-box tests.

## Goal

A conformance suite that proves the CLI is fully self-describing and its error/exit
contract is stable — the property agents rely on to discover capabilities.

## Scope

- `tests/conformance/cli/`: cases for every verb's --help (recursive walk of `ds
  --help` output), `ds schema <name>` for all five schemas matching schemas/*.json
  byte-for-byte (or semantically), `ds describe` on representative paths, each exit
  code with its exact stderr shape, `--json`/`--ndjson` rules incl. streaming-verb misuse
  → exit 1, `ds migrate` → exit 1, composition examples from cli.md §6.
- `docs/components/cli.md`: only if a tested behavior contradicts it — then fix doc and
  note in PR.

## Out of scope

Implementing missing verb behavior (that's the owning ticket — this suite may initially
SKIP verbs whose tickets are not done; the walk must report coverage, never silently
pass), WS/HTTP adapter (DS-074), runbook (DS-064).

## Implementation notes

Read docs/contracts/cli.md (all), docs/AGENT-WORKFLOW.md §self-description,
docs/30-testing.md §3. Data-driven cases so phase 3-5 tickets add cases as they land.
Coverage report: list verbs found vs verbs tested; a verb with no test fails the suite
once its ticket is done (coordinate via board states).

## Files and boundaries

Only `touches`: `new:tests/conformance/cli/`, `docs/components/cli.md` (gap fixes
only). Do not edit `bins/ds/` or `docs/contracts/cli.md` — contract is normative; a
needed change goes through the steward as a contract ticket.

## Acceptance

`python tests/conformance/run.py -k cli` exit 0 on the phase-1 verb set (later verbs
SKIP with reason until their tickets land); help-walk coverage report printed; every
exit code 0-8 exercised with exact stderr.

## Verification

conformance -k cli, fixture gate, workspace tests, check.sh, board validate — see
metadata.

## Risks

Exit-code drift as verbs are added — pin in this suite from day one. Help text churn
breaking the recursive walk — the walk must parse, not string-match.

## Definition of done

PR merged; self-description contract machine-checked; DS-063/064 can rely on it.

## Notes

This is the conformance home for "agents discover everything from the CLI alone".
