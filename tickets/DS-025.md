## Context

Phase 2 runs as a normal user; the hidraw device needs a udev rule so no root/sudo is
needed (docs/40-platforms.md §0 Linux-only). VID/PID come from the mh-protocol
device descriptors.

## Goal

Ship `packaging/udev/99-deckstack.rules` + install docs so the deck is usable by the
user session without root.

## Scope

- The udev rule file under `packaging/udev/` (hidraw, VID/PID of the MasterHub, mode
  0660, appropriate group/tag; also the usb device node if needed).
- `docs/40-platforms.md`: short install section (copy rule to
  /etc/udev/rules.d/, `udevadm control --reload-rules && udevadm trigger`, verify with
  `ls -l /dev/hidraw*`), keeping the Linux-only claims intact.
- Packaging hook note for later AppImage (DS-083) — do not implement.

## Out of scope

hid transport code (DS-021), systemd unit (DS-019), Windows/macOS (post-alpha TODOs).

## Implementation notes

Read docs/40-platforms.md §0/§1. Get VID/PID from the mh-protocol dependency (DS-010)
or docs/components/device-driver.md.

## Files and boundaries

Only `touches`.

## Acceptance

Fresh Bazzite/Fedora user session: rule installed → `ds daemon start --device hid:`
opens the deck without sudo; documented commands verified.

## Verification

udevadm verify; hardware enumerate-without-root; check.sh; board validate.

## Risks

Distro udev differences — test on Fedora (target) and note fallbacks.

## Definition of done

PR merged; rule + docs committed; permission flow proven on hardware.
