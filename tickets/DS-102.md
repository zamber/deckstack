## Context

First fresh-agent exercise (Vibe run `run-4004503968-63723`, 2026-11-24): a worker with only
`docs/agents.md` + the installed 0.1.0 CLI wrote a working status strip, but lost time on one
wrong guess. `agents.md` §3's path table calls `<data-dir>/daemon.sock` "what
`ds`/`ds-mcp`/`ds-py` connect to" and documents `ds --socket PATH --data-dir DIR` as
"override per invocation", which reads as if `--data-dir` alone relocates the client socket.
It does not: `ds --data-dir DIR get /controls/keys/0` dials the XDG default and exits 6
(E_UNREACHABLE). `ds --help` is accurate ("`--data-dir DIR` data dir for daemon
start/stop/status"), and `bins/ds/src/connect.rs:socket_path` uses only `--socket` or the
default, but the guide's table is the first thing a fresh agent reads.

Reproduced 2026-11-24 against `~/Applications/deckstack-0.1.0` with a daemon on a private
data dir: `ds --data-dir DIR get /controls/keys/0 --json` → exit 6, message names
`/run/user/1000/deckstack/daemon.sock`; the same call with `--socket DIR/daemon.sock`
succeeds.

## Goal

A reader of `agents.md` §3 cannot make the `--data-dir`-alone mistake: the two flags' scopes
are explicit and every client-verb snippet shows a working private-daemon invocation.

## Scope

- `docs/agents.md` §3: after the path table, add a short paragraph splitting the flags:
  `--data-dir` selects the dir for `daemon start/stop/status` and holds `daemon.sock`,
  `token`, `state.json`; client verbs (`get`, `set`, `watch`, `describe`, `schema`, `status`)
  connect to `--socket` (default `$XDG_RUNTIME_DIR/deckstack/daemon.sock`).
- Fix the private-daemon snippets in §3 (and any later section that starts a daemon on a
  non-default data dir) to pass `--socket <data-dir>/daemon.sock` on client calls, matching
  `docs/microapps.md` §1.
- Keep the table's "what connects to it" wording scoped to `ds-mcp`/`ds-py` and the default
  data dir.

## Out of scope

Changing CLI socket-resolution behaviour (`--data-dir` for client verbs). The help text is
already correct; if a behaviour change is wanted, file it against `bins/ds/src/connect.rs`.

## Implementation notes

Read `docs/agents.md` §3 and `docs/microapps.md` §1 together; the micro-app guide already
passes both flags. Keep the addition to a few lines; the path table stays the reference.

start`) only if it helps the reader recognise the failure.
