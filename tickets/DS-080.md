## Context

Cross-cutting verification (docs/30-testing.md §3-4: contract tests with fuzzed +
recorded corpora; T4 image/frame bombs in docs/20-security.md §2). The IPC surface is
DS-012/DS-013, the conformance harness DS-018, the frame service DS-031. This ticket
owns the adversarial input layer on top of them.

## Goal

Machine-checked proof that malformed and hostile input at the IPC, state, and image
surfaces gets deterministic documented errors and never corrupts or kills the daemon.

## Scope

- `tests/fuzz/`: socket-level fuzzers (control NDJSON + DSF1 stream) seeded from
  tests/fixtures/ipc-examples.json and golden frames; verdict assertions per input;
  crash minimization loop documented (not run in CI nightly — a fixed corpus replays).
- `tests/limits/`: the T4 bomb matrix + connection/subscription/queue limits from
  ipc.md §5 and streaming.md §5; RSS and p99 assertions.
- Both run on ds-vdev, no hardware; wired into check.sh by DS-082 later.

## Out of scope

Security conformance mapping T1-T12 (DS-081), perf gates in CI (DS-082), the frame
service itself (DS-031), schema changes (propose via steward).

## Implementation notes

Read docs/contracts/ipc.md §2/§4/§5, docs/contracts/streaming.md §2/§5,
docs/20-security.md T4, docs/30-testing.md §4. Deterministic: seed the RNG, keep the
corpus checked in, verdicts must be exact E_* codes or documented closes. A hang or
panic is a finding — file it, don't retry-loop.

## Files and boundaries

Only `touches`: `new:tests/fuzz/`, `new:tests/limits/`. Do not edit schemas, contracts,
daemon crates, or tests/conformance (DS-018) — reuse its process helpers by import.

## Acceptance

Fuzz corpus replays green with exact verdicts; limits suite proves caps with RSS/p99
budgets; daemon health asserted after every case.

## Verification

fuzz + limits runners, conformance, fixture gate, workspace tests, check.sh, board
validate — see metadata.

## Risks

Flaky timeouts under fuzz — per-case wall-clock budget with generous margin; nondeterminism
kills trust — seed everything. Corpus growth — cap it, minimize quarterly via a
scheduled job, not in PRs.

## Definition of done

PR merged; hostile-input behavior is deterministic and documented; DS-082 can gate it
in CI.

## Notes

Cross-cutting: phase field 6 because it gates the alpha, but it spans IPC/state/frames.
