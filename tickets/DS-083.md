## Context

Cross-cutting: release flow is specified in docs/50-repo-topology.md §4/§7 (subtree
splits, tags, CI artifacts, umbrella tag per coordinated release). Inputs: systemd unit
DS-019, udev rules DS-025, licenses DS-004, wheel DS-052, green gates DS-082. Scope:
Linux-only alpha — no MSI/wxs build in alpha (Windows packaging is DS-072's phase).

## Goal

One command produces a signed-checksummed Linux release: binaries + tar/AppImage +
systemd unit + udev rules + wheel, with per-component repos/tags published per the
topology doc.

## Scope

- `packaging/release/`: release.sh (version bump helper, subtree split + push per
  component, tag, artifact build, SHA256SUMS, GitHub release via gh or documented
  manual fallback), `--dry-run` mode.
- `packaging/linux/`: AppImage spec + desktop-file/systemd/udev install layout.
- `.github/workflows/release.yml`: tag-triggered build + gate + attach (Linux only).

## Out of scope

Windows MSI (DS-072 phase), macOS bundle (DS-073 phase), PyPI upload mechanics beyond
building the wheel (DS-052 owns the package; upload at release time by owner),
flathub/snap, auto-updater.

## Implementation notes

Read docs/50-repo-topology.md §4/§7, packaging/bootstrap.sh, docs/30-testing.md §8,
docs/00-scope.md (Linux-only). Keep release.sh boring shell; dry-run must be the
default in PRs. Artifacts reproducible where feasible (SOURCE_DATE_EPOCH).

## Files and boundaries

Only `touches`: `new:packaging/release/`, `new:packaging/linux/`,
`new:.github/workflows/release.yml`. Do not edit packaging/bootstrap.sh (DS-003) or
DS-019's unit file — consume them.

## Acceptance

Dry-run output correct; local artifact build + `sha256sum -c` green; workflow YAML
valid; runbook install steps match the artifact layout.

## Verification

Dry-run + local build evidence, fixture gate, workspace tests, conformance,
check.sh, board validate — see metadata.

## Risks

Subtree-split mistakes (wrong prefix) — dry-run prints commands; steward reviews before
any real push. GitHub release permissions — document required secrets, don't invent.

## Definition of done

PR merged; first real release can be cut by following release.sh dry-run output.
