## Context

Development exposed several bugs that were reported in chat before they had a reproducible
artifact. `tools/report-issue` and `skills/report-issue/SKILL.md` are the interim mechanism;
they already produce a Markdown bundle with git revision, daemon/device/control state, USB and
HID inventory, service status and the recent log. The native CLI verb is missing.

## Goal

`ds report` is the one command an operator or agent runs to capture enough evidence to file a
ticket, without reading source or guessing which diagnostics matter.

## Scope

- Add the `report` verb to `bins/ds/src/cli.rs` (and `ds --help`), with `--out` and `--log-lines`.
- Reuse the collection logic from `tools/report-issue` (or move it into a small library).
- Document the verb and the `report-issue` skill in `docs/agents.md`.
- Keep the bundle free of tokens and secret material; include state and log excerpts only.

## Out of scope

Automatic ticket creation, upload, or contacting a service. The bundle is local Markdown.

## Implementation notes

The script is a working reference: it uses argv-only subprocesses and bounded timeouts. The
CLI verb must follow the exit-code contract and write to a file; stdout stays a one-line path
unless `--json`. Do not print the daemon token.

## Files and boundaries

`skills/report-issue/SKILL.md`, `tools/report-issue`, `docs/agents.md`, `bins/ds/src/cli.rs`.
Protected: `BRIEF.md` R1-R12, `docs/discovery/`, `docs/reviews/`.

## Acceptance

- `ds report --help` documents the verb and the file it writes.
- `ds report --out /tmp/issue.md` exits 0 and the file contains the sections above.
- The existing script remains usable until the verb ships.

## Verification

`tools/report-issue --out /tmp/issue.md` (tested; 612-line bundle at the time of writing);
`python3 tools/tickets.py validate`; `cargo test -p ds-cli`.

## Risks

Error output can contain environment details; redact tokens and never include the socket token.
Bounded subprocess timeouts prevent a wedged daemon from hanging the report.

## Definition of done

A user who says "the deck did X" can attach one `ds report` bundle and a ticket.
