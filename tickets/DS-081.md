## Context

Cross-cutting verification: docs/20-security.md §2 defines T1-T12 with a "Test"
column; today most rows point at prose or at per-phase suites scattered around. The
safety subset landed as DS-029, exec as DS-043, plugin abuse as DS-053. This ticket makes
the whole table executable and auditable.

## Goal

A single security conformance runner that maps every threat T1-T12 to a concrete,
reproducible test and reports green/red — no threat covered only by prose.

## Scope

- `tests/conformance/security/`: the T1-T12 runner + any missing case glue (reusing
  DS-018/029/043/053/080 cases by reference, adding only what's absent, e.g. T9
  rotation race case, T1 no-token/E_SCOPE matrix).
- `docs/20-security.md`: §2 Test column rewritten to name test path + command per row;
  §6 non-goals stay honest (root/user themselves, plugin using granted caps maliciously).

## Out of scope

Implementing the underlying mitigations (owned by DS-012/024/029/043/053/074/080/072);
new security features; hardware-only rows get a documented pointer, not a fake test.

## Implementation notes

Read docs/20-security.md (all), docs/30-testing.md §3, tickets DS-029/043/053/080 for
existing case paths. The runner is a table-driven script over existing conformance
selectors (-k …) so it never duplicates logic. T12 is Windows-only — status
"covered-by DS-072 phase, not runnable on Linux" is an acceptable documented skip.

## Files and boundaries

Only `touches`: `new:tests/conformance/security/`, `docs/20-security.md` (Test column +
pointers). Do not edit other test dirs or protected files.

## Acceptance

Runner prints T1-T12 all green or documented-skip, exit 0 on vdev; the doc table matches
the runner output 1:1 (a test asserts the doc lists the same rows).

## Verification

security runner, fixture gate, workspace tests, conformance, check.sh, board
validate — see metadata.

## Risks

Doc/test drift as cases move — the 1:1 assertion mitigates. Skip rows being abused to
hide gaps — each skip needs a reason string and an owning ticket/job.

## Definition of done

PR merged; `python tests/conformance/security/run.py` is the single security gate
DS-082 wires into CI.
