## Context

The daemon is one long-lived Rust binary owning all state and hardware (ADR-001,
docs/components/daemon.md). The walking skeleton wires together the pieces from
DS-011/012/014: a state task, the IPC server, a device task, lifecycle + token + logs.
Telemetry sampled ≤ 1 Hz into /telemetry (never persisted).

## Goal

`ds daemon start` works end to end on the virtual device: socket + token + empty state
+ get/set + clean shutdown.

## Scope

- `crates/ds-daemon` binary crate: arg parsing for `start --device <uri>`, data dir
  (`$XDG_RUNTIME_DIR/deckstack/` fallback `~/.local/state/deckstack/`, dir 0700,
  socket 0600, token file 0600).
- Tasks: state task (owns ds-state, applies transactions from IPC), IPC server task
  (ds-ipc control plane, scoped token auth), device task (ds-device virtual transport,
  pushes state changes like key images to the device), telemetry sampler ≤ 1 Hz.
- Lifecycle: clean start, `ds daemon stop`/SIGTERM path (basic clean exit now; guard
  handback is DS-024), structured logs.
- `crates/ds-client`: the client library the CLI uses (if not already landed with
  DS-012 — coordinate; if DS-012 landed it, this ticket only consumes it and the
  touch is redundant, remove it in that case).
- Tests: unit tests per module; integration test starting the daemon on a tmp dir with
  a mock virtual socket.

## Out of scope

CLI (DS-016), vdev (DS-017), frame plane wiring beyond a stub (DS-013/DS-031),
router/bindings (phase 4), plugins (phase 5), guard/handback (DS-024), systemd unit
(DS-019).

## Implementation notes

Read docs/components/daemon.md, docs/contracts/ipc.md §1.1 (endpoints/paths), ADR-001.
Keep the binary thin: logic in modules so phases 3-5 extend it. Token: random, 0600,
instant revocation via re-read (per DS-012). Empty state at start — assert it in the
integration test.

## Files and boundaries

Only `touches`: `crates/ds-daemon/`, `crates/ds-client/` (only if not already created
by DS-012).

## Acceptance

Integration test + manual smoke: daemon starts on virtual device, empty state doc,
control socket answers hello/auth + one set/get round-trip, SIGTERM exits 0.

## Verification

`cargo test -p ds-daemon`; raw NDJSON smoke with python3 socket client; `sh
tools/check.sh`; board validate.

## Risks

Blocking the async runtime on state ops — keep transactions short; device task must
not stall IPC (separate tasks, bounded channels).

## Definition of done

PR merged, integration test green, daemon starts/stops cleanly on vdev.
