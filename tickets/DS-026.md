## Context

Roadmap phase-2 exit (docs/60-roadmap.md): `DS_HARDWARE=1 python tests/hw/smoke.py`
green on the real deck — enumerate, handshake, one frame per target, liveness ≤ 100 ms,
replug ≤ 5 s, SIGTERM handback, forbidden → `E_DEVICE` + zero bytes. AGENTS.md lists
this command; CI uses vdev only.

## Goal

A single hardware smoke entry point that proves the phase-2 device path end to end on
the real deck and skips cleanly without hardware.

## Scope

- `tests/hw/smoke.py`: steps — enumerate (hid transport finds the deck), handshake
  (DS-022), push one frame per target and verify via the device, liveness ≤ 100 ms,
  replug ≤ 5 s (unplug/replug, DS-023), SIGTERM handback (DS-024), forbidden command →
  `E_DEVICE` and zero bytes written (DS-029 asserts deeper; smoke checks the surface).
- Env gate: `DS_HARDWARE=1` required, else print SKIP and exit 0. Timeouts on every
  step; no retry-loops — a flake is a finding to record.
- Reuse the conformance harness process helpers where useful.

## Out of scope

Camera verification (DS-027/028), safety conformance depth (DS-029), perf benches.
