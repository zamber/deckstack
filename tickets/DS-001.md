## Context

The ticket/worktree/PR workflow (docs/AGENT-WORKFLOW.md, ADR-016) needs a board tool so
parallel workers cannot collide and the steward can triage. The tool landed in commit
e781422 ("tools: ticket board CLI and empty board scaffold") as a Python 3 stdlib-only
CLI.

## Goal

Provide the normative board tool: parse the fenced ```json metadata block + body of
each `tickets/DS-*.md`, and the commands list/show/ready/claim/state/unclaim/recover/
validate/sync/graph/index/lanes with flock locking and atomic writes.

## Scope

Already implemented and smoke-tested by the previous run — evidence:

- `python3 -m py_compile tools/tickets.py` → compiles clean.
- `python3 tools/tickets.py validate` on the empty board → `OK - 0 tickets, DAG valid,
  generated files in sync.`
- `python3 tools/tickets.py ready`, `graph`, `index`, `lanes`, `list` all run without
  error on the empty board.
- Empty scaffold committed: `tickets/BOARD.md`, `tickets/GRAPH.md`, `tickets/index.json`
  (commit e781422). `.gitignore` already covers `tickets/.lock`, `.worktrees/`,
  `.review.git/`.

This ticket covers only the tool itself; tickets/README.md and TEMPLATE.md are part of
the board landing (this run), and wt.sh/pr.sh are DS-002.

## Out of scope

tools/wt.sh, tools/pr.sh, tools/check.sh, CI (DS-002/DS-003); any feature code; the
phase 3-7 tickets (a later run).

## Implementation notes

Format contract (see tickets/TEMPLATE.md): metadata block first, body sections
Context/Goal/Scope/Out of scope/Implementation notes/Files and boundaries/Acceptance/
Verification/Risks/Definition of done/Notes. validate enforces unique ids, required
fields, enums, dep existence, DAG (no cycles), state-vs-deps (ready/doing/review/done
need all deps done), doing file collisions via `touches` overlap, and `touches` path
existence (`new:` prefix declares a to-be-created path). sync auto-promotes backlog →
ready when all deps are done and regenerates index.json/BOARD.md/GRAPH.md.

## Files and boundaries

`tools/tickets.py`, `tickets/` (board files). Do not touch docs/discovery/ or
docs/reviews/.
