## Context

DS-098 documents how an agent *connects* (install, daemon, MCP, ds-py). The main goal is
different and larger: an agent writes small programs that drive the deck on demand — a status
strip, a focus panel, a git indicator — learning the API from `ds --help` / `ds schema` /
`ds describe` instead of reading a large doc. MCP stays as the native-control path; the primary
authoring surface is the CLI with complete, agent-friendly help text and a short scripting guide
with runnable examples.

## Goal

An agent that has never seen the project can run `ds --help`, `ds <verb> --help`,
`ds schema state`, `ds describe <path>` and then write and run a small micro-app against the
deck (or vdev) without reading the source.

## Scope

- `bins/ds/src/help.rs`: audit and complete every verb's help — usage, arguments/flags with
  defaults, one runnable example, exit codes, and pointers to `ds schema`/`ds describe`. Keep the
  help discovery-first and short per verb; groups keep a one-line summary each.
- `docs/microapps.md`: the authoring guide — discovery loop (help/schema/describe), the state
  path map an app needs (`/controls/…`, `/settings`, `/policy`, `/focus`, `/telemetry/*`), events
  and `ds watch --ndjson`, images (`--file`, colour, target table), bindings as declarative
  behavior, when to write a script vs a plugin, rate limits and the 1 Hz attention rule, error
  and exit-code handling, and a 30-line worked example.
- `examples/microapps/`: three stdlib-only programs, each with `--once` and `--loop`, cleanup and
  `--socket/--data-dir` flags:
  * `status_strip.py` — CPU/mem/time across keys at <=1 Hz via `ds set`/`ds get`;
  * `focus_panel.py` — `ds watch --ndjson app/focus/changed` and renders the focused app on the
    panel/dial (uses the DS-060 sender or its own D-Bus/zwlr probe, documented);
  * `gitdeck.py` — keys 0-3 show clean/dirty/ahead/behind for a repo by polling `git status`.
- `tests/conformance/microapps/run.py`: starts vdev + daemon, runs one micro-app with `--once`
  and asserts the resulting state, plus the `--help` content assertions for every verb.
- `docs/agents.md` and `AGENTS.md`: link the authoring route and extend the upkeep rule to it.

## Out of scope

New daemon features; MCP tool changes; the web client.
