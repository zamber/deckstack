## Context

Phase 0 must prove the ticket/worktree/PR workflow end to end on a harmless change
before any real code lands. This ticket is that proof: it touches exactly one new,
content-free doc file. The workflow tooling itself is DS-001 (done) and DS-002
(worktree/PR scripts); in practice claim this ticket only after DS-002 is done.

## Goal

Exercise the full loop — claim, worktree, commit, PR submit, steward review, merge,
ticket done, worktree removed — by adding a single harmless file
`docs/workflow-smoke.md`, and leave the file on main as evidence.

## Scope

- Claim: `python3 tools/tickets.py claim DS-000 --owner <your-name>`
- `sh tools/wt.sh new DS-000 --owner <your-name>` (creates `.worktrees/DS-000`, branch
  `ticket/DS-000`)
- Add `docs/workflow-smoke.md` containing a few lines of markdown stating it is workflow
  smoke-test evidence (date, ticket, commands run). Nothing else.
- Commit with `ticket(DS-000): add docs/workflow-smoke.md` plus the
  `Generated by Mistral Vibe.` / `Co-Authored-By: Mistral Vibe <vibe@mistral.ai>`
  trailer.
- `sh tools/pr.sh submit DS-000`; steward runs `sh tools/pr.sh review DS-000` (approve)
  and `sh tools/pr.sh merge DS-000`.
- Confirm `python3 tools/tickets.py show DS-000` has state `done` and
  `git worktree list` no longer shows `.worktrees/DS-000`.

## Out of scope

Any other file. No changes to tools/, docs/ (other than the one new file), or the
board generated files. No feature code.

## Implementation notes

Read `AGENTS.md`, `docs/AGENT-WORKFLOW.md`, `tickets/README.md` first. If a workflow
script fails, fix the script only under its own ticket (DS-002) or report to the
steward — do not work around it silently. Do not leave stale worktrees, branches, or a
dirty main.

## Files and boundaries

Only `new:docs/workflow-smoke.md`. Protected files (BRIEF.md R1-R12, docs/discovery/,
docs/reviews/) must stay untouched — `git diff main -- BRIEF.md docs/discovery
docs/reviews` must be empty.

## Acceptance

`docs/workflow-smoke.md` is present on main; the board shows DS-000 done; the PR record
`prs/DS-000.md` exists with an approved verdict and merge commit.

## Verification

`python3 tools/tickets.py validate` exits 0; `git log --oneline main` shows the
ticket(DS-000) work; `python3 tools/tickets.py recover` shows no dangling DS-000
worktree/branch.

## Risks

Workflow scripts (DS-002) may have bugs on first real use — that is the point of this
smoke ticket; record any failure in the PR record so DS-002 can be fixed.

## Definition of done

PR merged, DS-000 state `done` on main, worktree and branch removed, smoke file kept.
