## Context

Frames are bytes on a separate binary stream (ADR-005, docs/contracts/streaming.md,
schemas/stream-frame.json): latest-frame-wins, bounded queues, dedicated writer threads
later (phase 3); this ticket is the wire protocol and flow control only. Invariant S1:
pushing a frame updates no durable state and no rev; acks are counted in telemetry
only.

## Goal

Implement the DSF1 frame plane in ds-ipc: stream socket `<dir>/stream.sock`, binary
frame encoding per schemas/stream-frame.json, `DSctl` NDJSON stream control, credits,
acks/nacks, and limits.

## Scope

- DSF1 frame codec (encode/decode) with schema-conformant headers; unit tests with
  golden vectors added to the fixture corpus if the format allows.
- Stream socket server side: accept, per-connection credit window, ack/nack per
  frame, per-target and global rate/size limits, backpressure signal.
- Test that the frame plane has no path to the state document (compile-time separation:
  ds-ipc frames module takes no ds-state handle).

## Out of scope

JPEG encode/chunking (DS-030, phase 3), frame service queues/writer threads (DS-031),
daemon integration (DS-015 uses it), CLI stream verbs (DS-032, phase 3).

## Implementation notes

Read docs/contracts/streaming.md and schemas/stream-frame.json (normative).
Coordinate with DS-012 on the shared `crates/ds-ipc/` tree: DS-012 owns the control
modules, this ticket owns `src/frames/` — do not claim both simultaneously unless
sequenced; the collision checker only guards `doing` overlaps, so sequence explicitly.

## Files and boundaries

Only `touches`: `crates/ds-ipc/src/frames/`, `docs/contracts/streaming.md`,
`schemas/stream-frame.json`.

## Acceptance

Round-trip tests: push N frames on a tmp stream socket, verify acks, credit exhaustion
→ backpressure, oversize frame → nack + limit error, zero state/rev interaction.

## Verification

`cargo test -p ds-ipc`; `sh tests/fixtures/validate.sh`; `sh tools/check.sh`; board
validate.

## Risks

Binary format mistakes are hard to debug — golden vectors in tests from day one.

## Definition of done

PR merged, codec + flow-control tests green, S1 invariant asserted.
