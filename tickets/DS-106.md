## Context

On 2026-11-24 15:54:35 the deck was reconnected in a different orientation. The daemon logged
`device disconnected` followed by `device task stopped`; the process stayed alive with
`device_status: disconnected`, `NRestarts=0`, and did not reopen the device. A service restart
recovered it. `crates/ds-daemon/src/device.rs` `run_loop` breaks on `DeviceEvent::Disconnected`
and on non-timeout device errors, so the hotplug `Lifecycle` is never re-entered. The systemd
unit was changed to `Restart=always` and a watchdog timer was added as an interim guard.

## Goal

A USB disconnect or a device-task error leaves the daemon running and it reopens/re-handshakes
the device with backoff.

## Scope

- Replace the `break` on disconnect/error with an outer reconnect loop (or use the existing
  `hotplug::Lifecycle` rescan API).
- Drain pushes while disconnected; publish disconnected and connected events.
- Keep the device task bounded and shutdown-aware.
- Add a vdev kill/restart test.

## Out of scope

Base orientation handling beyond the existing event; multi-device addressing.

## Implementation notes

Three hand-edits of the loop failed to compile, so this ticket starts from a clean design rather
than incremental braces. `hotplug.rs` already implements `Reconnecting` and rescan backoff;
prefer reusing it over a second state machine. The watchdog is a workaround, not the fix.

## Files and boundaries

Only the three `touches`. Protected: `BRIEF.md` R1-R12, `docs/discovery/`, `docs/reviews/`.

## Acceptance

- vdev kill/restart leaves the daemon connected without `systemctl restart`.
- No busy loop when the device is absent; log rate bounded.
- Existing daemon tests pass.

## Verification

`cargo test -p ds-daemon --lib`; private vdev socket kill/restart;
`python3 tools/tickets.py validate`.

## Risks

The reconnect loop touches the hot path; a blocking open or an unbounded rescan can stall
pushes. Keep the open bounded and the sleep between attempts.

## Definition of done

A physical replug recovers without manual service intervention; the watchdog remains a guard.
