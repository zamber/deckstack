## Context

DS-099 landed the micro-app authoring route (`docs/microapps.md`, `--help`-first discovery)
and three runnable examples (`status_strip.py`, `focus_panel.py`, `gitdeck.py`). The gallery
should grow into the things people actually put on a deck; now-playing is the most useful
next one, and it exercises D-Bus reading from a micro-app.

## Goal

A now-playing micro-app that a stranger can copy, run against vdev, and adapt.

## Scope

- `examples/microapps/now_playing.py`: stdlib-only; `--once` and `--loop`; `--socket` and
  `--data-dir`; reads the first MPRIS player on the session bus (D-Bus via
  `dbus-send`/`gdbus` or raw socket with a documented, tested path) and renders
  title/artist/playback state; <= 1 Hz; clean shutdown; documents the no-player path.
- `examples/microapps/README.md`: add the example to the table, with the adaptation notes.
- `docs/microapps.md`: mention it in the gallery list and in the events/D-Bus section.
- `tests/conformance/microapps/run.py`: add the case: vdev + daemon, run `--once` (stub
  player or the no-player path), assert the state written; never require a real player.

## Out of scope

New daemon features, MCP tool changes, album art streaming, the web client.

## Implementation notes

Read `docs/microapps.md`, `examples/microapps/*.py`, `tests/conformance/microapps/run.py`,
`docs/contracts/cli.md`. Keep it dependency-free; if D-Bus needs an external command,
detect its absence and fall back with a clear message (the conformance test covers the
fallback path).

## Acceptance

The example runs against vdev with `--once` and the conformance case passes; docs updated.

## Verification

`python tests/conformance/microapps/run.py`, full conformance, `sh tools/check.sh`, board
validate.

## Risks

D-Bus libraries vary by host; the fallback path must be the tested default in CI.

## Definition of done

PR merged; the gallery has a now-playing example that runs in conformance.
