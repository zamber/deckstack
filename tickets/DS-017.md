## Context

CI and conformance run on a virtual device, never hardware (ADR-015,
docs/components/virtual-device.md). ds-vdev is a report-level virtual MasterHub over a
Unix socket speaking the ds-device report codec; ds-vdevctl is its inspection/control
CLI. PLAN.md walking skeleton steps 3 and 6 use them.

## Goal

`ds-vdev` + `ds-vdevctl` binaries that make the whole phase-1 system testable with zero
hardware.

## Scope

- `crates/ds-vdev` (lib) + `bins/ds-vdev`: serve the virtual hub on `--socket <path>`:
  module reports for the deck layout, receive image/color pushes as chunked reports and
  reassemble (verify sha256), keep per-target latest frame with its sha.
- `inject`: inject device input events (for phase 4, stub now) via ds-vdevctl.
- `throttle`: artificial latency/drop knobs for bench/conformance (used by DS-033/035
  later).
- `bins/ds-vdevctl`: `frames <target>` (print sha256 of reassembled frame), `reports`,
  `inject`, `throttle` subcommands.
- Tests: reassembly correctness, sha mismatch rejection, report round-trips, multiple
  targets.

## Out of scope

Real HID (phase 2), JPEG encoding (DS-030), frame-plane streaming to vdev (DS-031/035).

## Implementation notes

Read docs/components/virtual-device.md and the ds-device transport trait (DS-014) —
the socket protocol must match exactly what DS-014's virtual transport speaks. Keep
vdev deterministic by default; throttle only when asked.

## Files and boundaries

Only `touches`. Do not edit crates/ds-device (DS-014's area) — if the trait needs a
change, note it in the PR and let the steward sequence.

## Acceptance

Smoke: with ds-vdev running, `ds set /controls/keys/0/image --file examples/key.png`
then `ds-vdevctl --socket /tmp/vdev.sock frames key:0` prints the same sha256 the
conformance suite will assert (DS-018/DS-020).

## Verification

`cargo test -p ds-vdev`; scripted smoke; `sh tools/check.sh`; board validate.

## Risks

vdev/hardware divergence — if real hardware later behaves differently, fix vdev first
(escalation rule in docs/AGENT-WORKFLOW.md).

## Definition of done

PR merged, smoke green, conformance can run against vdev only.
