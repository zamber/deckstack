## Context

Phase 6 agent surfaces (docs/60-roadmap.md): beyond ds-mcp (DS-061), agents benefit from
a small Python client helper — the task taxonomy lists "Python/CLI client helper for
agents (optional thin wrapper over ds/API)". Contracts: docs/contracts/ipc.md (NDJSON
API), cli.md (exit codes). ds-client (Rust) is DS-012/015; this is the Python-side
convenience, kept optional per R1 (CLI-first).

## Goal

An optional, thin, well-tested Python client + one example agent, proving an agent can
drive the deck with a few lines — without any special daemon surface.

## Scope

- `clients/ds-py/`: `DeckClient` (socket path/token discovery per ipc.md §1.1/§3:
  `$XDG_RUNTIME_DIR/deckstack/daemon.sock` fallback `~/.local/state/deckstack/`),
  methods get/set/watch/emit/bind/unbind/stream-stats, NDJSON subscribe iterator,
  error classes carrying E_* codes; stdlib-only (socket+json) so it runs anywhere.
- `examples/agents/`: one example (focus→recolor or cron-style emit→binding demo)
  runnable against vdev; README pointing at ds-mcp for MCP clients.

## Out of scope

ds-mcp itself (DS-061), ds-focus (DS-060), CLI changes, daemon changes, WS/HTTP adapter
(DS-074), publishing (decide PyPI name at DS-083; default: not published in alpha —
copyable single file is fine, record decision).

## Implementation notes

Read docs/contracts/ipc.md §2-4, docs/contracts/cli.md §3, docs/components/mcp-bridge.md.
Keep it < 300 lines. The example must be exercised in conformance (spawn vdev+daemon,
run example, assert effect).

## Files and boundaries

Only `touches`: `new:clients/ds-py/`, `new:examples/agents/`. Do not edit `bins/`,
`crates/`, `plugins-py/` (DS-052), docs/contracts.

## Acceptance

Helper tests green; example agent runs against vdev and produces the expected state
change; README states plainly that the `ds` CLI alone is sufficient (R1).

## Verification

pytest for the client, example run, fixture gate, workspace tests, conformance,
check.sh, board validate — see metadata.

## Risks

Scope creep into a full SDK — keep it thin; anything more belongs in ds-plugin-py or
ds-mcp. Token handling — read-only from the 0600 token file, never log it.

## Definition of done

PR merged; an agent author can go from zero to a working script in minutes on vdev.

## Notes

If the steward decides the helper is unnecessary (CLI is enough), mark blocked with
reason rather than building a parallel API.
