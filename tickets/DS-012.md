## Context

The control plane is NDJSON over a Unix socket at
`$XDG_RUNTIME_DIR/deckstack/daemon.sock` (dir 0700, socket 0600), with hello/auth,
scoped tokens, an error envelope, and body limits (ADR-003, docs/contracts/ipc.md,
schemas/ipc-message.json). The example corpus tests/fixtures/ipc-examples.json is
validated by the fixture gate. No `migrate` op exists (scope invariant).

## Goal

`ds-ipc` implements the server and wire plumbing for the control plane; `ds-client`
is the client library shared by `ds`, ds-focus, ds-mcp, and agents.

## Scope

- Server: bind Unix socket, per-connection NDJSON framing (one request → one
  response), max line/body limits, timeouts.
- hello handshake with `protocol: 1`; token auth against the token file (0600);
  scopes (read/write/admin) enforced per op; instant revocation (token file re-read).
- Error envelope with stable codes per docs/contracts/ipc.md; unknown op → usage error
  (exit-code mapping lands with the CLI in DS-016).
- Message validation against schemas/ipc-message.json on both sides; extend
  tests/fixtures/ipc-examples.json with any new message shapes so the fixture gate
  covers them.
- `crates/ds-client`: one-shot request API + watch subscription API used by the CLI.
- Tests: round-trip against a mock in-process server, auth failures, oversized
  payload rejection, revoked token rejection.

## Out of scope

The DSF1 frame plane (DS-013), daemon wiring (DS-015), the CLI itself (DS-016).

## Implementation notes
