## Context

Phase 6 closes the alpha with operator-facing docs. AGENTS.md lists the operational
commands; docs/AGENT-WORKFLOW.md §Verification defines the acceptance gates; DS-019
lands the systemd unit; DS-024 guard/handback; T9 token rotation. Scope rules apply:
no migrate verb, Linux only, empty state (docs/00-scope.md).

## Goal

A single operator runbook that takes a user from install to running daemon to routine
operations and recovery, with every command proven against vdev.

## Scope

- `new:docs/runbook.md`: the sections listed in acceptance — all commands real
  (`ds daemon …`, `ds token …`, `systemctl --user …`, `ds-vdevctl …` for testing),
  with expected output shapes and exit codes.
- `README.md`: add the runbook link in the docs index section.
- No code changes; if a command doesn't exist yet (e.g. a verb from an unfinished
  ticket), mark it clearly as pending its ticket instead of inventing behavior.

## Out of scope

Implementation of any missing command (owning tickets), the agent workflow doc
(AGENT-WORKFLOW.md — steward territory), release/packaging docs (DS-083), web UI
(DS-074).

## Implementation notes

Read AGENTS.md, docs/AGENT-WORKFLOW.md, docs/contracts/cli.md §5, docs/00-scope.md,
docs/60-roadmap.md. Write for an operator, not a developer: symptom → command →
expected result → exit code. Verify each command's output on vdev while writing.

## Files and boundaries

Only `touches`: `new:docs/runbook.md`, `README.md` (index link only). Do not edit
protected files (BRIEF.md, docs/discovery/, docs/reviews/) or other docs.

## Acceptance

Runbook complete per the acceptance list; commands executed with outputs in
prs/DS-064.md; README links it; no stale claims (no migrate, no web UI, Linux-only).

## Verification

Command outputs recorded, fixture gate, check.sh, board validate — see metadata.

## Risks

Doc drift as tickets land — each PR that adds a verb updates the runbook if it's
operator-visible (steward checklist item). Commands that need hardware — mark
"hardware run" explicitly, never claim unverified results.

## Definition of done

PR merged; runbook reviewed against a fresh vdev session; alpha operators have one
place to look.

## Notes

The runbook doubles as the ds-focus/ds-mcp session-autostart instructions (DS-060/061).
