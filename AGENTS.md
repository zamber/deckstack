# AGENTS.md — working in deckstack as an agent

Operational short version. Long protocol: `docs/AGENT-WORKFLOW.md`. Scope/invariants:
`docs/00-scope.md`. Index: `README.md`. Entry point: `PLAN.md`.

## Read order (first session)

1. `BRIEF.md` (R1–R12 + Scope amendment 2026-11-22) → 2. `docs/00-scope.md` →
3. `PLAN.md` → 4. `docs/contracts/` + `schemas/` (contracts are normative) →
5. `docs/components/` for the component you touch → 6. `AGENTS.md`/`docs/AGENT-WORKFLOW.md`
   (this file is step 6) → 7. your ticket.

## Invariants (never violate; conformance tests enforce them)

- Linux-only alpha; empty state at start; no presets/sample decks; no `ds migrate`; no web
  UI; CLI-first (every capability reachable via `ds` with no UI).
- Contracts are normative: change `schemas/*.json` and `docs/contracts/*` in the same
  commit; keep `sh tests/fixtures/validate.sh` green (ALL CHECKS PASSED).
- No `eval` of config, no shell spawns; exec is argv-only + `/policy/exec` allow−deny.
- Frames never enter JSON state or bump `rev` (S1); stats in `/telemetry` only.
- Forbidden HID commands stay unrepresentable (mh-protocol safety); never backlight-0 the
  dial; software-mode handshake before reads.

## Commands

```sh
sh packaging/bootstrap.sh                 # build + fixture gate + venv
sh tests/fixtures/validate.sh             # schema/fixture gate (must print ALL CHECKS PASSED)
cargo test --workspace                    # unit
python tests/conformance/run.py           # black-box CLI/API suite (vdev, no hardware)
DS_HARDWARE=1 python tests/hw/smoke.py    # hardware smoke (phase 2+; needs deck + camera)
ds daemon start --device virtual:/tmp/vdev.sock   # local demo
```

## Work protocol (summary — details in docs/AGENT-WORKFLOW.md)

- One worktree per ticket: `.worktrees/<id>` from `main`, branch `ticket/<id>`.
- Never commit to `main`. PR record at `prs/<id>.md`; steward reviews, runs acceptance,
  merges. Check file-ownership collisions before claiming a ticket.
- Commit format: heredoc with `Generated by Mistral Vibe.` + `Co-Authored-By: Mistral Vibe
  <vibe@mistral.ai>` trailer. Small, ordered commits; verify each unit before the next.

## Definition of done (per ticket)

Tests green (`validate.sh` + `cargo test` + conformance), docs/schemas updated in the same
commit, PR record filled, no edits to protected files (`BRIEF.md` R1–R12,
`docs/discovery/`, `docs/reviews/`), stale-grep clean for your area.

## Report shape

Status, what works, what is not done, next step, proving command — the same shape as the
run report. Under 400 words.
